# Политика проверки (слой «политика»)

`policy.csv` — решения по спорным местам из таблицы «Спорные места в правилах проверки»
(заполнена 29–30.09). Одна строка = одна ситуация, исход задан для двух режимов:

- `exam` — задачи в формате экзамена (варианты, банк ФИПИ, «Задание 1–6» про кредиты);
- `training` — тренажёры (задачник Ширяевой), школьная программа, контрольные, ОГЭ часть 1.

Исходы: `error` — ошибка (is_correct = 0); `remark` — не ошибка, но сказать ученику; `ignore` — не упоминать;
`blank` — не размечать (пусто); `answer_only` — проверяем только ответ; `curator` — к куратору;
`as_solved` — проверять то, что ученик на самом деле решал.

Строгость не меняется в течение года (13.5). Пометки проверяющего (12.7–12.10): «+» неверному → ошибка
с пометкой; зачёркнуто верное → верно с пометкой; только комментарий → решаем по математике; пропуск
проверяющего → ошибка.

Детектор (LLM) сообщает, какая ситуация случилась (id из этого файла или «other»), политика (код) по режиму
задания решает исход. Режим задания берётся из карточки (`data/cards/*.csv`, колонка `mode`).
