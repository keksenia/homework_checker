## Твоя ML-часть (по data/features.csv)
Цель `model_wrong` (вердикт модели не совпал с разметкой) — «когда отдавать задачу человеку».
- Признаки: verdict/pred_error, n_err_*, key_vs_student (ответ ученика совпал с ключом), key_vs_model_answer
  (модель сама решила верно?), frac_incorrect/vote_entropy (при --repeats), reasoning_per_task,
  legibility_mean/min, unclear_marks_*, n_pages, effort_check. Служебные (не признаки): run, work, task_no,
  student_id, task_key, split, student_answer, model_correct_answer, key_answer, human_missed, label.
- Бейзлайны: «верить всегда», правило «key_vs_student не совпал → к человеку», логрегрессия, бустинг.
- Кросс-валидация: GroupKFold по task_key (или student_id) — задачи одной работы/задания зависимы.
- Калибровка: reliability diagram, ECE, Platt/isotonic (sklearn CalibratedClassifierCV).
- Итог: кривая «доля задач на автомате ↔ доля пропущенных ошибок», рабочая точка (напр. пропуск ≤ 5%).
- Анализ A/B «думания» и «с фото/без»: парные сравнения по одним задачам, тест Мак-Немара,
  bootstrap-интервалы по работам, график цена ↔ качество.
- Для эксперимента с уверенностью: на пилоте `--repeats 3` на выбранном уровне (+2× цена проверки).
