## 4. Гипотезы (те же пороги, что в первом протоколе, чтобы не двигать планку)
- H1: совпадение вердиктов проверки ≥ 92%. Проверка не менялась; на первом test было 90,4% — ожидаем, что H1 может
  не выполниться, и сообщаем это заранее.
- H2: recall ≥ 90% (первый test: 95,9%).
- H3: итоговое совпадение с учётом куратора ≥ 97,5% при доле задач к куратору ≤ 15% (оценка на dev + первом test,
  out-of-fold: 98,5% при 11,7%; вложенная CV: к куратору 13,9%).
- H4: доля задач с непойманной ошибкой проверки ≤ 2% (сообщаем верхнюю 90%-границу Клоппера–Пирсона).
Все метрики — с 95% bootstrap-интервалами по работам. Результат публикуется в любом случае (TEST_RESULTS_2.md).
