# Как присылать работы на проверку

Эти правила не обязательны: система проверяет и без них. Но каждое снимает конкретный источник ошибок —
см. разбор расхождений в EXPERIMENTS.md, п. 18 (чтение ответа ≈39 из 101 расхождения, номера задач ≈22,
рисунки в условии ≈8).

## Ученику

1. **Номер задачи — в начале решения, ровно как в задании**: «№85», «1.2», «13 а)». Пункты подписывать
   «а)», «б)». Не перенумеровывать по-своему («Ф1», «задача 1» вместо «№85»).
   *Зачем:* иначе система не понимает, к какой задаче относится решение (главная причина промахов test2).
2. **В конце каждой задачи — отдельная строка «Ответ: …».** Писать чётко:
   - скобки промежутков: круглая «(», квадратная «[» — не наполовину;
   - дробь — дробью, десятичную запятую — заметно;
   - исправленный ответ — зачеркнуть целиком и написать новый рядом, а не поверх.
   *Зачем:* неверно прочитанный ответ — самая частая причина ложной тревоги (131 → 731, 2,5 → 225, «(2» → «[2»).
3. **Фото:**
   - одна страница — одно фото, лист целиком, снимать сверху, без тени и наклона;
   - в Telegram отправлять **файлом** («Отправить как файл»), а не фото — иначе картинка сжимается и мелкие
     цифры и скобки теряются;
   - страницы — по порядку решения.
4. Черновик и чистовик лучше разделять; если черновик на том же листе — отчеркнуть.

## Репетитору

1. **Условие — PDF или текстом, не фотографией листа.** Для задач банка ФИПИ достаточно номеров. Рисунки
   (графики, чертежи) — исходной картинкой.
   *Зачем:* ошибки чтения рисунков в условии (≈8 из 101) уходят полностью, а одно и то же условие для всей
   группы распознаётся один раз.
2. **Карточка задания** — CSV в `data/cards/` (образец `data/cards/_template.csv`), одна на задание:

   | колонка | что писать |
   |---|---|
   | task_no | номер ровно как в условии: `85`, `3.4`, `13а` |
   | works | работы учеников с этим заданием через пробел |
   | mode | `exam` — формат экзамена, строго (ответ ровно на заданный вопрос); `training` — тренировка, лояльно; `criteria` — баллы по критериям ФИПИ (в разработке) |
   | answer, answer_type | ответ (можно пусто) и тип: number, interval, set, series, pair, expression, text, proof |
   | source | откуда задача: `ФИПИ 85`, `Ширяева №03 с. 4`, `вариант 36483 №13` |
   | criteria | набор критериев (для `criteria`, в разработке) |
   | comment | пояснение к ответу |

   Загрузка: `python3 card.py data/cards/<файл>.csv` (проверка) → `--write` (ответы попадут в ключ,
   список задач — в `<файл>_scope.csv` для `check.py --scope-file`).
   *Зачем:* номера сверяются с фиксированным списком, а режим строгости задаёт человек, а не угадывает модель.
3. **Для первой части ЕГЭ/ОГЭ — бланк ответов** (таблица «номер → ответ» внизу листа или отдельным листом).
   Таблицу система читает почти без ошибок.
